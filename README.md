## Overview

UpiSense is an all-in-one developer platform for building AI-powered expense tracking and financial management tools, seamlessly integrating WhatsApp messaging with backend services and real-time dashboards. It provides a robust architecture, detailed documentation, and scalable components to accelerate your project development.

### Why UpiSense?

This project empowers developers to create secure, scalable, and user-friendly financial apps with ease. The core features include:

- 🔴 **Modular Architecture:** Comprehensive source code with clear milestones, onboarding, and troubleshooting guides.
- 🟢 **WhatsApp Integration:** Webhook setup, message parsing, and real-time communication for effortless user engagement.
- 🟡 **AI-Powered Parsing:** Leverages regex and generative AI to accurately extract transaction data from diverse messages.
- 🔴 **Secure Authentication:** Email and phone OTP workflows with Firebase and Supabase integration.
- 🟢 **Rich Frontend Components:** React-based UI with TailwindCSS for engaging dashboards and user interfaces.
- 🔵 **Deployment & Testing:** End-to-end scripts, CI/CD setup, and detailed deployment instructions for reliable releases.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** JavaScript
- **Package Manager:** npm

### Installation

Build UpiSense from the source and install dependencies:

1. **Clone the repository:**
```bash
git clone https://github.com/kushalmehta2004/UpiSense
```

2. **Navigate to the project directory:**
```bash
cd UpiSense
```

3. **Install the dependencies:**

Using [npm](https://www.npmjs.com/):
```bash
npm install
```

### Usage

Run the project with:

Using [npm](https://www.npmjs.com/):
```bash
npm start
```
